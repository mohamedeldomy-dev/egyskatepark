System & connection

🌐 Connect Online

Right now everything is saved on this computer only. To share data live between the desk and phones, we connect to a free Google cloud (Firebase). Ask Claude to set this up with you — it takes 15 minutes. Then paste the config here and press Connect.

🔐 Owner PIN (anti-cheating)

Set a secret PIN only you know. Deleting payments, deleting members, disconnecting from online, and opening the activity log will all ask for it. Staff can add — only you can remove.

📟 This device

Give this device a name (e.g. "Desk PC", "Mohamed phone"). When online, every device reports itself so you can see from your phone that the desk is alive.

💾 Backup

Download a backup file of everything (bookings, members, payments). Keep one every week. You can restore it on any computer.
